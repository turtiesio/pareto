# Change and execution pressure corpus

Cases: inventory reservation, cancellation, payment authorization, refund, approval, message send, infrastructure mutation, and file replacement.

For each cover concurrency, atomic final guard, idempotency, retry, partial failure, crash before/after commit, lost response, unknown outcome, reconciliation, compensation, duplicate/out-of-order delivery, stale reads, and policy change racing action. A timeout is never silently equated with failure.
