# Longevity pressure corpus

Assume the original runtime, language, database, UI, vendor, and organization are gone. Reconstruction receives only formal specification, canonical export, format definitions, hash algorithms, test vectors, and version/migration history.

Test deterministic encoding, exact numbers, Unicode rules, semantically relevant ordering, unknown-field retention, content-address verification, implementation agreement, and explicit external assumptions. No format choice is accepted solely because it is current or popular.
