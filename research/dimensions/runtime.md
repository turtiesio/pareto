# Runtime and query cost (R/Q)

For point lookup, bounded traversal, authorization, derivation, incremental update, history, proof, aggregate, and diff, record measured or modeled CPU, allocation, IO, latency, lookups, and asymptotic dependence on world size `N`, relevant neighborhood `k`, rules `R`, and proof depth `d`.

Generic interpretation and specialized/compiled execution must be compared under equivalent workloads.
