# ZERO GROUND — first milestone

Date: 2026-09-01

## Outcome

There is no contract-independent smallest persistent representation or smallest
total system. The permitted future-observation language determines the
equivalence relation:

- If the future language contains every predicate of prior boundary bytes, any
  two different histories are separable and the quotient is literal history.
- If future evolution is confined to functions of an already declared residual
  behavior, histories can merge to that residual class.
- If the future language, observation equality, environment, or boundary is
  incomplete, equivalence is not false; it is unverified.

Likewise, no single smallest **total** implementation follows from the logical
quotient. Without a scalar score, sound candidates form a partial order. A
dense code, a replayable representative, and a lossless trace move cost among
persistent bits, semantic machinery, runtime, cognition, operations, TCB,
evolution, and loss risk. Unknown measurements block dominance claims.

The defensible first milestone is therefore conditional. For the fully frozen
finite B1 laboratory contract, the information that must survive is exactly the
current future-behavior class. The experiment identifies the responsibilities
that separate those classes, what is mechanically rebuildable, and which raw
history distinctions are forgettable. It does not promote the laboratory
vocabulary to an architecture.

## Quarantine and correction history

The builder candidate and ontology-free breaker suite were produced
independently and hashed before `../ground.md` was opened. The archive turned
out to be the restart charter itself, not an older solution. Its replay added
acceptance attacks but no inherited structure or concrete old counterexample.

Fresh breaking then invalidated B0 as an executable specification: several
frames and ports were undefined; intersection-only continuation domains could
hide a distinction; the history horizon was not transition-closed; `UNKNOWN`
could not serve as an equivalence value; canonical byte order was unspecified;
and one oracle path created common-mode risk. B0 remains immutable evidence of
those failures. `CONTRACT-B1.md` totalizes only the finite experiment, using
union-domain proof enumeration, exact frame bytes/order, complete cuts, and no
unknown cells in equivalence. Its `enabled`/`disabled` values are proof markers
for next-crossing-domain membership, never unrecorded physical response frames.

## MUST SURVIVE in B1

At a cut, enough information must survive to select one of 1,192 tested
classes—at least 11 fixed-width information bits for that bounded cut set. A
transition-closed implementation over the whole frozen finite value domain must
select one of 82,584 boundary-phase classes—at least 17 information bits. These
are information lower bounds only; framing, redundancy, error correction,
specification, code, recovery, and verification remain additional.

The exhaustive ten-coordinate deletion grammar has four sound masks and one
inclusion-minimal kept set:

```text
current_source, current_bit,
rule_label, rule_on_1,
action_k, action_l,
owed_kind, owed_arguments
```

These names belong only to the falsification oracle. Each line below states the
surviving responsibility and its smallest bounded direct-deletion witness; it
does not establish a field, type, constructor, record, or layer.

| Surviving responsibility | Histories made identical by deletion | Future-observable split |
|---|---|---|
| current source distinction | `P(a,0)` / `P(b,0)` | `A(k);resume` emits different `DO` source |
| current payload distinction | `P(a,0)` / `P(a,1)` | `A(k);resume` emits different `DO` payload/result |
| selected explanatory label | empty / `R(u,0,1)` | `P(a,0);A(k);resume` emits label `d` / `u` |
| latent behavior on input 1 | `R(u,0,0)` / `R(u,0,1)` | `P(a,1);A(k);resume` emits result `0` / `1` |
| action responsibility for `k` | `P(a,0)` / the same plus crossed `DO(k,…)` | only the latter next-crossing domain contains `ACK(k)` |
| action responsibility for `l` | `P(a,0)` / the same plus crossed `DO(l,…)` | only the latter next-crossing domain contains `ACK(l)` |
| owed-output kind | no-content `A(k)?` / `S(k)?` | `resume` emits `NO_DATA` / `ABSENT` |
| owed-output arguments | no-content `A(k)?` / `A(l)?` | `resume` emits key `k` / `l` |

Additional minimized/golden collisions show responsibilities inside those
opaque coordinates:

- empty versus present content changes `NO_DATA` to `DO`;
- the latest accepted occurrence and its ordering change observation/action;
- pending versus acknowledged action changes future status;
- an action retains its captured decision when current content later changes;
- action-key association changes next-crossing-domain membership and status;
- an owed output versus the same already-crossed output changes whether
  `resume` emits at a logical cut. Fresh-process reconstruction of every
  generated logical cut is exercised in B3; physical output-delivery recovery
  and durable crash semantics remain unsupported.

The ordinal candidate demonstrates that none of these responsibilities entails
a dedicated constructor: all are jointly encoded in an otherwise meaningless
class number.

## MAY REBUILD in B1

Given the surviving class and the exact, available B1 specification:

- `rule_on_0` is the frozen constant `0` throughout the grammar;
- output port is determined by output kind;
- `RAW`, `VAL`, `WHY`, `DO`, `ALREADY`, and status output bytes are generated;
- ordinal, canonical-representative, and transition mappings regenerate
  deterministically;
- lookup indexes, caches, checksums, search aids, and human renderings add no
  history distinction;
- the one tested `current_b1_observer` can be generated over the 62,528-history
  corpus because it is constant on every tested old encoding cell. No broader
  positive evolution result is claimed.

The clean rebuild produced identical specification digest, rank order,
representatives, and transition cells. This does not make rebuilding free. The
specification bundle, generator, parser, verifier, runtime, dependency
availability, and rebuild time remain charged to storage, operations, and TCB.

In a singleton deployment whose exact B1 specification is fixed externally, a
per-instance digest is not history-witnessed MUST information. Its B2
in-process encoding is 64 UTF-8 hexadecimal characters; B3 packs those digest
bits into 32 bytes inside its envelope. It may be omitted, but doing so moves
correct bundle selection into deployment
configuration and TCB. If specification choice becomes a contract-visible
environment/history distinction, a version-selection responsibility must then
survive. SHA-256 collision resistance is assumed, not proved.

## MAY FORGET in B1

The following pairs have equal stable classes and pass the hidden required-
equivalence tests:

- overwritten content versus only its latest replacement;
- overwritten rule selection versus only its latest replacement;
- `P` then `R` versus `R` then `P` when their resulting responsibilities agree;
- a completed observation/query/explanation/status turn versus its absence;
- a completed no-content action attempt versus no attempt;
- one versus repeated completed retries while the action remains pending;
- restart count and timing, which B1 does not expose.

Consequently the actual past trace, occurrence count, discarded predecessors,
and completed read-only traffic may be forgotten after their surviving effects
are represented. A canonical representative can be rebuilt, but it is a
synthetic class name and must never be claimed as historical provenance.

These verdicts immediately fail if audit, billing, rate limits, raw replay,
time, retry counts, secure-erasure receipts, or another separating observer is
added to the permitted future language.

Candidate B exposes a compact behavioral example and fits unlike sequential
encodings. Neither is known no worse in every total-system dimension, and the
unmeasured human/physical dimensions prevent a dominance claim.

The storage figures are non-additive, incomplete proxies. They exclude Python
objects and allocator overhead, interpreter and OS, filesystem framing, durable
boundary capture, packaging, logs, redundancy, and physical media. The
executable spec/verifier inventory is separately reported as 131,089 bytes and
3,253 physical lines across eight files; that too is not a total deployment
size. B3 additionally uses a 40,424-byte process/envelope probe and a 5,789-byte
focused verifier. Its all-class test streams are 3,716,290 bytes for the ordinal
encoding and 18,053,209 bytes for the representative encoding; those streams
are exhaustive test batches, not required per-instance deployment state.

A literal trace is a third useful attack baseline. It preserves B1 but retains
many distinctions the quotient proves unnecessary, grows without bound, and
has linear replay cost. It can be easier to inspect and can accommodate some
future class-splitting extensions. It is therefore not an exact B1 quotient
encoding, but it exposes where state-minimal candidates moved evolution risk.

## Evolution and unlike realization results

The sole positive result is `current_b1_observer`, which factored through each
old encoding on the 62,528-history corpus; no general positive evolution result
is claimed. An observer that counts all prior `P` crossings conclusively fails:
the E03 histories `P(a,0);P(b,1)` and `P(b,1)` share both old encodings but
require counts 2 and 1. No deterministic migration from either old quotient can
support that split. Arbitrary future interpretation and prior forgetting are
therefore incompatible.

The ordinal/table and text/replay implementations were differentially executed
against the same oracle. This validates two unlike software encodings and their
abstraction to one quotient. B3 additionally validates controlled file handoff
from an exited producer to fresh consumers on that same runtime and host. It is
**not** a cross-physical-media experiment.
Flash, optical, punched/mechanical, or other substrate interchangeability,
including their failure modes, remains `UNKNOWN` until actually realized and
run against the same histories across unlike media/runtimes, migrations,
relevant failure conditions, and the observation comparator.

## Where the complexity went

- Dense state deletion moved responsibility into a 238,884-cell generated
  table, class generator, decoder, artifact binding, and verifier.
- Trace deletion moved historical flexibility into a sealed evolution
  envelope; a later split cannot be reconstructed.
- Output-port deletion moved a deterministic kind-to-port relation into the
  specification.
- Constant-rule deletion moved the constant and its validity range into the
  specification.
- B1 has no dedicated rejection channel: rejected proposals are proof-level
  non-events. Domain selection still lives in specification, executable
  selector code, and TCB. A real refusal response would cross the boundary,
  enlarge history, and require a new experiment.
- Digest deletion removes a same-runtime artifact-mismatch guard and moves exact
  artifact selection into deployment operations and TCB; it is not a general
  portability mechanism.
- B3 envelope framing moves cross-process decoding into magic/version/tag/length
  bytes plus a 40,424-byte codec/probe. Its artifact digest selects semantics but
  does not protect state payload integrity; an integrity mechanism remains an
  operational/TCB responsibility rather than zero complexity.
- Index/cache deletion moves work into recomputation. The measurement only
  clears an in-process replay cache; B3 executes fresh processes but records no
  startup benchmark.
  B1 declares no deadline, so this is informationally rebuildable but not
  operationally free.
- Human-readable provenance deletion moves interpretation to tools or people;
  cognition remains unmeasured, not zero.

## What this milestone does not establish

- The real target contract has not been declared concretely, so no B1 bit or
  name is universally required.
- Global future completeness and global program/description minimality are not
  claimed.
- All 709,836 corpus-class pair branches have executed minimized bounded
  witnesses. The certificate exhausts every minimum-crossing corpus history in
  each class and all contexts through the earliest separating depth; this is
  still only the declared finite corpus/future grammar, not a global proof.
- Irreducibility is relative to the declared ten-coordinate transform grammar;
  arbitrary recoding minimality is not computable from this experiment alone.
- Crashes inside boundary capture, torn writes, physical delivery ambiguity,
  deadlines, concurrency/reordering, time, audit, authorization, privacy,
  malformed/fresh values, and physical effects beyond crossed `DO` are
  unsupported.
- Actual cognition, human authoring/error rates, operational recovery procedures
  beyond B3's controlled file handoff, energy, unlike runtimes, and unlike
  physical media are unmeasured or unsupported.
- Literal goldens and a deliberate corrupted-table test reduce common-mode
  risk, but the oracle, candidates, tests, CPython runtime, and host still share
  assumptions.

Within those limits, the first milestone is complete: the surviving
responsibility is the B1 future-behavior class; its eight directly addressable
pressures have minimized collisions; two apparent coordinates rebuild; the
listed history differences may be forgotten; and every omitted mechanism or
external specification is charged rather than counted as zero.
